# TinyMacro

**A simple, powerful Windows macro recorder.**

TinyMacro is a Windows desktop automation tool that records and replays mouse and keyboard actions, helping you automate repetitive tasks with ease.

## ✨ Features

- 🖱️ **Mouse Recording** — Record mouse movements, clicks, and scrolling.
- ⌨️ **Keyboard Recording** — Capture keyboard inputs and replay them automatically.
- ▶️ **Playback Controls** — Play, pause, resume, and stop macros.
- 🔁 **Repeat & Loop** — Repeat macros a specified number of times or loop indefinitely.
- ⚡ **Adjustable Speed** — Customize macro playback speed.
- 💾 **Save & Load** — Save macros and load them whenever you need them.
- 🌙 **Dark Interface** — A clean, modern dark-themed UI.
- 📦 **Standalone Executable** — Run TinyMacro using the Windows executable without installing Python separately.

## 🚀 Getting Started

1. Go to the [Releases](../../releases) page.
2. Download `TinyMacro.exe` or the release package provided.
3. Open the downloaded file to launch TinyMacro.
4. Start recording your actions and play them back whenever needed.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + Alt + R` | Start/Stop Recording |
| `Ctrl + Alt + P` | Start Playback |
| `Ctrl + Alt + S` | Stop Playback |

## ⚠️ Important Notes

- TinyMacro sends real mouse and keyboard input to your desktop.
- Test macros in a safe environment before using them for important tasks.
- Infinite loops continue until you stop playback.
- Windows SmartScreen or antivirus software may warn about an unsigned executable.
